
# IMJ — Personal Portfolio Website

## Introduction

This project is my personal portfolio website, developed using HTML, CSS, and JavaScript as part of my university coursework at Universiti Malaysia Sarawak (UNIMAS).

The main purpose of this website is to showcase my technical projects, skills, education, work experience, and learning journey as a Computer Science (Network Computing) student.

I wanted to create a portfolio that reflects my interests in Linux, networking, cybersecurity, and technology.

Instead of using frontend frameworks or website builders, I developed the website using HTML, CSS, and JavaScript to strengthen my understanding of web development fundamentals.

I also wanted the website to have its own identity rather than following a typical portfolio template. This led me to experiment with a space-inspired design, network-style navigation, interactive elements, and animations.

**Project Type:** Individual University Project

**Technologies:** HTML, CSS, JavaScript

**Project Status:** Initial version completed; improvements ongoing

---

## Project Objectives

The main objective of this project was to design and develop a personal portfolio website that presents my background, technical interests, and projects in an organized and accessible way.

My objectives included:

- Building a responsive website using HTML, CSS, and JavaScript.
- Creating a personal identity through custom branding and design.
- Showcasing my technical projects and practical experience.

## Website Features

### 1. Responsive Design

The website was designed to support different screen sizes, including desktop computers, laptops, tablets, and smartphones.

I used CSS media queries and responsive layouts to adjust the appearance of different sections.

During development, I tested and modified the layout to improve the experience on smaller screens.

### 2. Custom Navigation System

Instead of using a traditional navigation menu, I experimented with a network-inspired navigation design.

The mobile version includes a custom network-style menu icon that allows users to open and close the navigation links.

I also implemented a clickable personal logo that allows users to return to the top of the website.

This feature was designed to give the portfolio a unique identity while maintaining basic navigation functionality.

### 3. Space-Inspired Design

The website uses a space and technology-inspired visual theme.

Some design elements include:

- Dark blue background colours.
- Network-grid patterns.
- Technology-inspired navigation elements.
- Custom branding using the IMJ logo.
- Interactive animations.

The design reflects my interest in technology, networking, and space exploration.

### 4. Rocket Animation

I implemented a rocket animation using CSS and JavaScript.

The animation responds to scrolling behaviour and adds a visual element to the website.

During development, I adjusted the animation behaviour and positioning to improve its appearance across different devices.

I also considered reduced-motion preferences to improve accessibility.

### 5. About Me Section

The About section introduces my background as a Computer Science (Network Computing) student at UNIMAS.

It includes information about my interests, education, and technical learning journey.

### 6. Technical Skills Section

The Skills section presents technologies and areas that I have explored, including:

- Linux and system administration.
- Computer networking.
- Cybersecurity fundamentals.
- HTML, CSS, and JavaScript.
- Programming and development tools.
- Virtualization.
- Hardware maintenance and troubleshooting.

I also experimented with interactive elements that allow users to explore additional skill information.

### 7. Projects Showcase

The Projects section highlights technical projects and experiments that I have worked on.

Some of the projects and activities featured include:

- Debian Linux optimization.
- Debian home server and Syncthing.
- JohorCore (JCoreIQ) hackathon project.
- Virtual machine experiments.
- Programming and development tools.
- Blender experiments.

Each project is presented with information about its purpose and development.

I also implemented interactive project details to allow visitors to explore additional information.

### 8. Education and Work Experience Timeline

I developed a timeline section to present my education and work experience.

The timeline provides an organized way to display important stages of my learning and professional journey.

I also experimented with expandable elements to improve interaction.

### 9. Contact Section

The website includes a contact section with a form.

I used JavaScript to implement client-side form validation.

The validation helps check user input before the form is processed.

This feature helped me understand basic form handling and user input validation.

Client-side validation alone does not provide a backend messaging service or guarantee successful message delivery.

---

## Challenges Encountered

### 1. Responsive Layout Issues

One of my challenges was making the website display properly on both desktop and mobile devices.

Some elements appeared differently depending on the screen size.

I adjusted CSS properties and media queries to improve the layout.

### 2. JavaScript Functionality Problems

During development, some interactive features stopped working after I modified the JavaScript code.

I later identified a misplaced bracket that affected the script.

After correcting the issue, I was able to restore the affected functionality.

This experience helped me understand how a small syntax mistake can affect multiple JavaScript features.

### 3. Project Image Display

Some project images did not appear correctly on the website.

I investigated the image paths and file references to correct the problems.

This helped me understand the importance of managing file names and relative paths in web development.

### 4. Interactive Project Details

I encountered problems with the View Details functionality in the Projects section.

I reviewed the HTML structure and JavaScript behaviour while troubleshooting the issue.

After making corrections, the project details interaction worked as intended during testing.

### 5. Animation Behaviour

I experimented with scroll-triggered animations and encountered difficulties making some effects behave consistently.

I made adjustments to improve the behaviour of the rocket animation and other interactive elements.
